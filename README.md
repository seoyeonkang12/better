- bxSlider: 인스타그램 콘텐츠의 자동 이동형 슬라이더

라이브러리의 기본 기능을 활용하면서 사이트의 각 영역에 필요한 슬라이드 동작을 적용했습니다.

## 🔍 문제 해결 및 개선 방향

### 1. JavaScript 라이브러리 중복 로드 정리

HTML에서 여러 버전의 jQuery와 복수의 슬라이더 라이브러리를 불러오는 부분을 확인했습니다.

개선 방향

- jQuery 버전을 통일하고 중복 로드 제거
- 실제 사용하지 않는 라이브러리 제거
- 라이브러리 간 충돌 가능성 확인
- 외부 리소스 로드와 실행 순서 정리

### 2. 스크롤 진행 표시 바 계산 수정

영상 콘텐츠의 진행 표시 바 코드에서 너비 계산 관련 오타와 최대 스크롤 거리 계산 오류를 확인했습니다.

개선 방향

- scrollWidth - clientWidth를 기준으로 최대 스크롤 거리 계산
- 콘텐츠가 넘치지 않는 경우 별도 처리
- 스크롤 위치에 따른 진행률 계산식 점검

### 3. 반복되는 이벤트 처리 개선

버튼의 호버 효과와 퍼스널 컬러 탭 이벤트 등 유사한 동작이 반복되는 부분을 확인했습니다.

개선 방향

- 공통 스타일은 CSS의 :hover로 처리
- 반복되는 JavaScript 이벤트를 함수화
- 여러 탭의 공통 동작을 하나의 이벤트 처리 로직으로 통합

### 4. 다양한 화면과 입력 방식 대응

마우스 이벤트를 중심으로 구현한 드래그 기능은 모바일 환경에서 별도의 확인이 필요합니다.

개선 방향

- 모바일 터치 동작과 스크롤 충돌 확인
- Pointer Events를 활용한 입력 처리 통합 검토
- 키보드 조작 및 접근성 보완
- 반응형 환경에서 상품 너비와 이동 거리를 일관되게 관리

## 📝 프로젝트 회고

이번 프로젝트를 통해 HTML과 CSS를 활용한 화면 구성뿐 아니라 JavaScript와 jQuery를 활용한 인터랙션 구현을 경험했습니다. 
메인 비주얼, 상품 탭, 퍼스널 컬러 추천, 드래그 기반 스크롤 등 다양한 UI 요소를 직접 연결하며 사용자 동작에 따라 화면을 제어하는 방법을 익혔습니다.

특히 탭 전환과 스크롤 위치, 진행 표시 바처럼 여러 요소가 서로 연결되는 기능을 구현하면서 각 요소의 상태와 이벤트 실행 흐름을 고려하는 것이 중요하다는 점을 배웠습니다.

또한 코드와 리소스 로드 방식을 검토하면서 기능을 구현하는 것뿐 아니라 중복 코드를 줄이고, 라이브러리 사용을 정리하며, 다양한 화면 환경에서 안정적으로 동작하도록 개선하는 과정도 중요하다는 점을 알게 되었습니다.

앞으로는 공통 기능의 재사용성을 높이고 반응형 레이아웃과 접근성을 고려해 유지보수하기 좋은 웹사이트를 구현할 수 있도록 개발 역량을 키워 나가겠습니다.
