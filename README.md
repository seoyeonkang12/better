# 💄 Better — 화장품 쇼핑몰

> **나에게 맞는 뷰티를 발견하다**
> 
> 피부 고민과 퍼스널 컬러를 바탕으로 다양한 뷰티 제품을 탐색할 수 있는 화장품 쇼핑몰입니다.  
> 상품을 둘러보는 과정이 조금 더 편리하고 즐거울 수 있도록 UI를 구성하고, 다양한 인터랙션을 구현했습니다.

## 📌 프로젝트 개요

Better는 다양한 뷰티 제품을 탐색하고, 피부 고민과 퍼스널 컬러에 맞는 상품을 찾아볼 수 있도록 기획한 화장품 쇼핑몰 프로젝트입니다.  
상품 정보와 할인 혜택을 직관적으로 전달하고, 상품 상세정보부터 리뷰와 배송 안내까지 자연스럽게 탐색할 수 있도록 UI를 구성했습니다.

- **프로젝트명 :** Better
- **작업 형태 :** 개인 프로젝트
- **개발 기간 :** 2026.05 ~ 2026.06 (총 2주)
- **작업 범위 :** 기획, UI 디자인, 퍼블리싱, 인터랙션 구현
- **작업 환경 :** PC 및 모바일 적응형 화면
- **주요 기술 :** HTML5, CSS, JavaScript, jQuery
- **사용 라이브러리 :** Swiper, bxSlider

## 🛠️ 기술 스택

- **Markup :** HTML5

- **Slider :** Swiper, bxSlider
- **Data :** JSON
- **Browser Storage :** localStorage

## 🎯 프로젝트 목표

- **상품 탐색 경험 개선 :** 피부 고민과 퍼스널 컬러 등 다양한 기준으로 상품을 탐색할 수 있도록 구성했습니다.
- **정보 전달력 향상 :** 상품의 가격, 할인율, 주요 성분, 사용 방법 등 구매 결정에 필요한 정보를 구분해 배치했습니다.
- **사용자 중심 UI 설계 :** 상품 상세정보와 리뷰, 배송 안내를 영역별로 구분해 필요한 정보를 쉽게 찾을 수 있도록 구성했습니다.
- **인터랙션 구현 :** 탭 전환, 슬라이드, 드롭다운 메뉴, 팝업 등 JavaScript와 jQuery를 활용한 동적 UI를 구현했습니다.
- **적응형 화면 구성 :** PC와 모바일 환경에서 주요 콘텐츠를 확인할 수 있도록 화면 구조를 설계했습니다.

## ✨ 주요 기능

### 1. 메인 페이지 (Main Page)

- 메인 배너 슬라이드 및 프로모션 콘텐츠 구성
- 피부 고민별 베스트 상품 및 컬러별 상품 탐색
- 퍼스널 컬러(봄·여름·가을·겨울)별 상품 콘텐츠 제공
- 상품 목록의 가로 스크롤과 스크롤 진행률 표시
- PC 드롭다운 메뉴와 모바일 카테고리 메뉴 구성
- 검색 팝업을 통한 인기 검색어 및 추천 상품 노출
- 신규 회원 혜택 팝업과 프로모션 콘텐츠 구성
- 인스타그램 콘텐츠 슬라이더 및 영상 영역 구현

### 2. 서브 페이지 (Sub Page)

- 상품 카테고리 및 피부 고민별 상품 목록 구성
- 카테고리 중심의 상품 탐색 UI 구성
- 메인 페이지와 연결되는 상품 탐색 흐름 설계

### 3. 상품 상세페이지 (Product Detail Page)

- 상품 대표 이미지 및 썸네일 전환 UI 구성
- 제품 설명·주요 성분·사용 방법 탭 구성
- 수량 조절 및 총 결제 금액 표시 UI 구현
- 찜하기 및 상품 공유 UI 구성
- 장바구니 담기 안내 팝업과 장바구니 이동 링크 구성
- 상품 상세 이미지 더보기 및 접기 UI 구성
- 별점·피부 타입·피부 고민·연령대별 리뷰 필터 UI 구성
- 하단 고정 구매 영역을 통한 구매 버튼 접근성 개선

### 4. 로그인 페이지 (Login Page)

- 회원 로그인과 비회원 주문 조회 탭 전환
- fetch()를 이용한 JSON 회원 데이터 불러오기
- find()를 활용한 아이디·비밀번호 일치 여부 확인
- 아이디 저장 기능 구현 (localStorage)
- 비회원 주문 조회를 위한 입력값 검증
- 입력값 검증 및 로그인·비회원 주문 조회 결과 안내

### 5. 공통 UI 및 인터랙션 (Common UI)

- 공통 헤더와 푸터 구성
- PC 및 모바일 화면에 대응하는 UI 구성
- 상품 찜하기 UI와 버튼 호버 효과 적용
- 검색 팝업, 드롭다운 메뉴 등 탐색 UI 구성
- 최근 본 상품 및 상단 이동 버튼
- jQuery와 JavaScript를 활용한 사용자 인터랙션

## 🎯 트러블슈팅

### 1. 가로 스크롤 진행률 계산

**문제**

가로 스크롤 영역의 진행률을 표시하는 과정에서 전체 콘텐츠 너비와 실제 스크롤 가능한 거리를 구분해야 했습니다.

**원인**

scrollWidth는 콘텐츠 전체 너비를 나타내고, clientWidth는 요소 내부에서 실제로 보이는 너비를 나타냅니다. 따라서 두 값의 차이를 이용해 실제 스크롤 가능한 거리를 계산해야 합니다.

**개선 코드**

<img width="434" height="162" alt="image" src="https://github.com/user-attachments/assets/bd205262-859e-4cc0-8c57-23d50fcc29e2" />

실제 스크롤 가능한 거리를 기준으로 진행률을 계산하고, 스크롤할 수 없는 경우에도 0으로 처리할 수 있도록 구성했습니다.

### 2. 로그인 입력 및 데이터 처리

**문제**

로그인 데이터가 비동기로 불러와지기 때문에 데이터 로딩이 완료되기 전에 로그인 버튼을 누르는 상황을 고려해야 합니다. 또한 Enter 키 처리와 주문 조회 예외 처리도 점검할 필요가 있습니다.

**개선 방향**

- JSON 데이터 로딩 완료 여부 확인
- 데이터 로딩 중 로그인 버튼 처리
- Enter 키 입력 시 실행되는 함수 정리
- 잘못된 함수명 등 오타 점검
- 입력값 검증과 오류 메시지 처리 통일


## 💻 코드 리뷰

**잘한 점**

- 페이지의 목적에 맞춰 상품 탐색, 상세정보, 리뷰, 로그인 화면을 구분했습니다.
- 상품 상세페이지에 제품 설명뿐 아니라 리뷰와 배송 안내까지 구성해 쇼핑몰의 정보 구조를 확장했습니다.
- JavaScript와 jQuery를 활용해 정적인 화면에 탭 전환, 슬라이드, 팝업 등의 인터랙션을 적용했습니다.
- JSON과 localStorage를 활용해 데이터 처리와 브라우저 저장 기능을 연습했습니다.

**아쉬운 점 및 개선 방향**

- **코드 재사용성 :** 여러 페이지에서 공통으로 사용하는 헤더와 UI 요소를 관리하는 과정에서 코드 중복을 줄이고 유지보수성을 높일 필요성을 느꼈습니다.
- **이벤트 처리 :** 탭과 버튼, 팝업 등 다양한 인터랙션을 구현하면서 이벤트별 역할을 명확하게 분리하는 것이 중요하다는 점을 배웠습니다.
- **데이터 관리 :** JSON 데이터를 불러와 입력값과 비교하는 기능을 구현하며, 데이터 로딩과 화면 동작을 함께 고려해야 한다는 점을 알게 되었습니다.
- **예외 처리 :** 정상적인 입력뿐 아니라 데이터 로딩 실패와 잘못된 입력 등 다양한 상황에 대응하는 처리를 보완할 필요가 있습니다.
- **접근성 :** 버튼의 목적을 명확히 하고, 이미지 대체 텍스트와 키보드 조작 가능 여부를 점검할 필요가 있습니다.
- **보안 :** 실제 서비스로 발전시킬 경우 로그인 인증과 개인정보 처리는 서버에서 수행하도록 개선해야 합니다.

## 📝 프로젝트 회고

이번 프로젝트를 통해 HTML과 CSS를 이용한 화면 구성뿐 아니라 JavaScript와 jQuery를 활용해 사용자 동작에 반응하는 UI를 구현하는 경험을 쌓았습니다.

특히 상품 상세페이지를 구성하면서 상품 정보, 리뷰, 배송 안내처럼 성격이 다른 콘텐츠를 구분하고, 사용자가 필요한 정보를 단계적으로 확인할 수 있도록 화면 구조를 설계했습니다.

또한 JSON 데이터 불러오기, 배열 메서드를 활용한 데이터 검색, localStorage를 이용한 아이디 저장 기능을 구현하며 브라우저에서 데이터를 다루는 기본적인 방법을 익혔습니다.

프로젝트를 진행하며 화면이 의도한 대로 보이는 것뿐 아니라, 버튼과 탭이 올바르게 동작하는지 확인하고 예외 상황까지 고려하는 과정이 중요하다는 점을 배웠습니다.

앞으로는 반복되는 코드를 줄이고 데이터 관리 구조를 개선해, 유지보수하기 쉽고 사용자에게 더 나은 경험을 제공하는 웹사이트를 구현하고 싶습니다.

## 🔍 문제 해결 및 개선 방향

### 1. JavaScript 라이브러리 중복 로드 정리

HTML에서 여러 버전의 jQuery와 복수의 슬라이더 라이브러리를 불러오는 부분을 확인했습니다.

개선 방향

- jQuery 버전을 통일하고 중복 로드 제거
- 실제 사용하지 않는 라이브러리 제거
- 라이브러리 간 충돌 가능성 확인
- 외부 리소스 로드와 실행 순서 정리

### 2. 스크롤 진행 표시 바 계산 수정

영상 콘텐츠의 진행 표시 바 코드에서 너비 계산 관련 오타와 최대 스크롤 거리 계산 오류를 확인했습니다.

개선 방향

- scrollWidth - clientWidth를 기준으로 최대 스크롤 거리 계산
- 콘텐츠가 넘치지 않는 경우 별도 처리
- 스크롤 위치에 따른 진행률 계산식 점검

### 3. 반복되는 이벤트 처리 개선

버튼의 호버 효과와 퍼스널 컬러 탭 이벤트 등 유사한 동작이 반복되는 부분을 확인했습니다.

개선 방향

- 공통 스타일은 CSS의 :hover로 처리
- 반복되는 JavaScript 이벤트를 함수화
- 여러 탭의 공통 동작을 하나의 이벤트 처리 로직으로 통합

### 4. 다양한 화면과 입력 방식 대응

마우스 이벤트를 중심으로 구현한 드래그 기능은 모바일 환경에서 별도의 확인이 필요합니다.

개선 방향

- 모바일 터치 동작과 스크롤 충돌 확인
- Pointer Events를 활용한 입력 처리 통합 검토
- 키보드 조작 및 접근성 보완
- 반응형 환경에서 상품 너비와 이동 거리를 일관되게 관리

## 📝 프로젝트 회고

이번 프로젝트를 통해 HTML과 CSS를 활용한 화면 구성뿐 아니라 JavaScript와 jQuery를 활용한 인터랙션 구현을 경험했습니다. 
메인 비주얼, 상품 탭, 퍼스널 컬러 추천, 드래그 기반 스크롤 등 다양한 UI 요소를 직접 연결하며 사용자 동작에 따라 화면을 제어하는 방법을 익혔습니다.

특히 탭 전환과 스크롤 위치, 진행 표시 바처럼 여러 요소가 서로 연결되는 기능을 구현하면서 각 요소의 상태와 이벤트 실행 흐름을 고려하는 것이 중요하다는 점을 배웠습니다.

또한 코드와 리소스 로드 방식을 검토하면서 기능을 구현하는 것뿐 아니라 중복 코드를 줄이고, 라이브러리 사용을 정리하며, 다양한 화면 환경에서 안정적으로 동작하도록 개선하는 과정도 중요하다는 점을 알게 되었습니다.

앞으로는 공통 기능의 재사용성을 높이고 반응형 레이아웃과 접근성을 고려해 유지보수하기 좋은 웹사이트를 구현할 수 있도록 개발 역량을 키워 나가겠습니다.
